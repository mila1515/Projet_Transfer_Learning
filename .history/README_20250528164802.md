# 🧠 Classification Automatique de la Pneumonie par Deep Learning

## 🩺 Présentation de la Maladie

**La pneumonie** est une infection des poumons touchant les alvéoles, souvent causée par des bactéries, virus ou champignons. Elle peut entraîner des complications graves, notamment chez les enfants, les personnes âgées et les patients immunodéprimés. Le diagnostic repose principalement sur l’analyse de radiographies thoraciques, un outil clé pour identifier les signes d’infection. L'automatisation de cette analyse par l’intelligence artificielle peut considérablement améliorer la rapidité et la précision du diagnostic médical.

## 📌 Description du Projet

Ce projet vise à développer un système de classification automatique de la pneumonie à partir de radiographies thoraciques (chest X-ray) en utilisant des techniques de Deep Learning. L’approche s’appuie sur le transfert de connaissances (transfer learning) et une évaluation complète du modèle avec des métriques médicales pertinentes.

## 🎯 Objectifs

- Réutiliser un modèle CNN pré-entraîné pour la classification de pneumonie
- Mettre en place un pipeline MLOps avec MLflow
- Documenter et tracer les expérimentations
- Créer un prototype fonctionnel pour validation médicale


##  Technologies Utilisées

## 📚 Description

- **Modèle utilisé** : VGG16 (pré-entraîné sur ImageNet, fine-tuning léger), ResNet50V2
- **Tâche** : Classification binaire (pneumonie vs normal)
- **Données** : Images issues du dataset [Chest X-ray](https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia)
- **Entraînement** : Data augmentation, early stopping, suivi avec MLflow . Références (https://mlflow.org/)
- **Évaluation** : Accuracy, matrice de confusion, courbe ROC/AUC, classification report

## 📝 Résultats VGG16

- **AUC ROC** : ~0.96
- **Sensibilité (recall)** : ~99.5% (très peu de faux négatifs)
- **Spécificité** : ~65% (quelques faux positifs)
- **Conclusion** :  
  Le modèle détecte très bien la pneumonie mais a tendance à surdiagnostiquer (faux positifs). Il est donc adapté pour un usage de triage ou d’aide au diagnostic, mais nécessite une validation médicale.
